# Frontend (React + Vite)

UPPMS SPA. Source is grouped by **domain** under `src/pages/` and `src/components/`.

See **[`src/DOMAINS.md`](src/DOMAINS.md)** for the full map (auth, projects, proposals, tracks, scheduling, …).

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Env: copy `.env.example` → `.env` with `VITE_API_BASE_URL`.
